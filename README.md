# Agensync

AI-powered business process automation platform. See [`CLAUDE.md`](./CLAUDE.md) for the full product and engineering specification.

## Status

Phase 1 (project foundation) — in progress. Currently set up: Next.js App Router, TypeScript strict mode, Tailwind CSS, ESLint. Docker/PostgreSQL/Prisma setup is not wired up yet — this section will be updated with full local setup instructions once that lands.

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
pnpm dev     # start the dev server
pnpm build   # production build
pnpm lint    # eslint
```
